Курс лекций и практических работ по моделированию бизнес-процессов (BPMN, EPC, IDEF0) и языку структурированных запросов SQL

О курсе

В современном бизнесе ключевыми компетенциями становятся умение формализовать бизнес-процессы и владение SQL для анализа накопленных данных. Курс объединяет эти две области: нормативные модели процессов сопоставляются с фактическими данными из баз данных для выявления узких мест и непрерывного улучшения.
